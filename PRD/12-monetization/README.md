# 12. Monetization & Operational Resource Model

## 12.1 Model Penggunaan Internal Institusi
Sistem **Edu-Test** adalah *in-house educational software* yang dikembangkan untuk kebutuhan internal **SMK Skill Village Islamic School**:
- Tidak menerapkan sistem langganan SaaS perorangan bagi calon santri.
- Biaya pengembangan dan operasional didanai oleh anggaran operasional PPDB/PSB tahun ajaran sekolah.

## 12.2 Estimasi Biaya Operasional per Periode Seleksi
1. **Infrastruktur Server / VPS**: Server cloud/lokal berkapasitas 2–4 vCPU, 4–8 GB RAM selama masa pendaftaran dan 2 minggu intensif ujian seleksi.
2. **Konektivitas & Perangkat Meja Penguji**: Akses WiFi dedicated di ruang wawancara dan penyediaan unit tablet penguji.
3. **Layanan Notifikasi (Opsional)**: Kuota WhatsApp Gateway API untuk pengiriman pengumuman nomor tes dan hasil seleksi.
