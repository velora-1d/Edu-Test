# 02 - List Fitur: Dashboard Admisi

## Daftar Fitur
1. **Statistik KPI Card**:
   - Total Pendaftar Aktif.
   - Total Peserta Selesai Dinilai (TPA + Kepesantrenan + Wawancara lengkap).
   - Peserta Pending / Belum Lengkap Dinilai.
   - Kuota Daya Tampung Tersedia vs Terisi.
2. **Progress Tracker per Ruang / Meja Penguji**:
   - Indikator persentase pengisian nilai di Meja TPA.
   - Indikator persentase pengisian di Meja Kepesantrenan.
   - Indikator penyelesaian lembar wawancara umum & ortu.
3. **Grafik Sebaran Nilai**:
   - Histogram distribusi skor TPA (kategori Sangat Buruk s/d Sangat Baik).
   - Bar chart rata-rata per bidang kepesantrenan (Tahsin, Kitab, Bahasa, Hadits, Adzan, Sholat).
4. **Quick Feed Aktivitas Terbaru**:
   - Log submit nilai terkini oleh penguji (dengan stempel waktu).
