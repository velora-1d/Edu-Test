# 03 - Filter & Pencarian: Dashboard Admisi

## Filter & Kontrol Tampilan
1. **Filter Gelombang Pendaftaran**: Pilihan dropdown (Gelombang 1, Gelombang 2, Gelombang Khusus).
2. **Filter Jurusan / Peminatan**: Pilihan jurusan (misal: RPL, DKV, Bisnis Digital, dll).
3. **Filter Sesi Ujian**: Filter berdasarkan tanggal pelaksanaan atau sesi pagi/siang.
4. **Auto-Refresh Toggle**: Tombol refresh otomatis (interval 30 detik / 1 menit) saat hari-H ujian berlangsung.
