# 03 - Filter & Pencarian: Manajemen Peserta

## Filter & Pencarian
1. **Search Bar**: Pencarian cerdas instan berdasarkan:
   - Nomor Tes
   - Nama Lengkap Calon Santri
   - Asal Sekolah
2. **Filter Multi-Kriteria**:
   - Filter Gelombang (Semua / Gelombang 1 / Gelombang 2)
   - Filter Jurusan Pilihan
   - Filter Status Ujian (Belum Lengkap / Lengkap Semua)
3. **Pagination & Sorting**:
   - Pilihan jumlah data per halaman (25, 50, 100 baris).
   - Pengurutan berdasarkan No Tes (ASC/DESC), Nama (A-Z), atau Waktu Pendaftaran.
