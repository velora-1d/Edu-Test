# 02 - List Fitur: Manajemen Peserta

## Daftar Fitur
1. **CRUD Peserta**:
   - Tambah peserta satuan.
   - Edit data calon santri (nama, nomor kontak, pilihan jurusan).
   - Hapus / Nonaktifkan peserta (soft delete).
2. **Import & Export Massal**:
   - Import peserta dari format Excel (.xlsx) / CSV.
   - Validasi duplikasi Nomor Tes atau NISN saat import.
   - Export daftar peserta dan lembar presensi ujian.
3. **Penerbitan Nomor Tes Otomatis**:
   - Generator nomor tes dengan pola terstruktur: `[GEL]-[JUR]-[NO_URUT]`, contoh: `G1-RPL-001`.
4. **Status Kelengkapan Berkas & Tes**:
   - Badge status: `Belum Diuji`, `Dalam Proses`, `Selesai Dinilai`.
