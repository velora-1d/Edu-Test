# 03 - Filter & Pencarian: TPA Scoring

## Filter & Pencarian
1. **Pencarian Peserta Cepat**: Pencarian instan berdasarkan No Tes atau Nama untuk langsung membuka form entri nilai siswa bersangkutan.
2. **Filter Status Input TPA**:
   - `Semua Peserta`
   - `Belum Diinput`
   - `Draft (Belum Dikunci)`
   - `Terkunci / Selesai (Final)`
3. **Filter Kategori Hasil TPA**:
   - Filter untuk melihat peserta dengan hasil `Sangat Baik`, `Baik`, `Sedang`, `Buruk`, atau `Sangat Buruk`.
