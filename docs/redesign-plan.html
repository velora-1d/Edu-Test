🔍 Diagnosis 7 Halaman Utama Aplikasi
Hasil inspeksi langsung terhadap baris kode template dan alur antarmuka pengguna saat ini:
1. Layout & Header Global (+layout.svelte) Issue: Clutter
  • Subheader Deskripsi Menghabiskan Ruang: Baris teks deskripsi di bawah navbar mengambil 42px vertikal hanya untuk menulis kalimat panjang pengantar yang statis.
  • Redundan Aksi: Tombol 'Rekap Nilai' dan 'Data Santri' muncul ganda di header kanan dan sidebar menu.
  • Footer Terlalu Ramai: Status DB, gelombang, dan lisensi shadcn bertebaran di sidebar bawah dan footer canvas.
2. Dashboard Seleksi (/ +page.svelte) Issue: AI-Slop
  • Basa-basi AI: Teks "Standar TPA: EYD, MTK, Logika...", "Tie-breaker aktif: Kepesantrenan -> Tahsin...", "💡 Info: Kuota kelulusan..." bertebaran seperti instruksi chat GPT.
  • Density Rendah: Grid radar 7 bidang berbentuk 8 kotak besar yang memakan 2 layar scroll ke bawah, padahal penguji butuh melihat ringkasan dalam 1 layar glanceable.
  • Tabel Top 5 Terpotong: Nilai TPA menampilkan format tumpuk yang tidak seragam dengan kolom nilai lainnya.
3. Master Data Santri (/peserta) Issue: Banner Raksasa
  • Hero Banner Raksasa: Box gradient biru setinggi 280px menceritakan "Alur Sistem Seleksi Masuk Pesantren" Langkah 1, Langkah 2, Langkah 3 yang harus di-scroll panitia setiap kali buka pendaftaran.
  • Keterangan T-K-W: Singkatan tes (T, K, W) butuh blok helper text di bawah tabel untuk dijelaskan karena tidak self-explanatory.
  • Modal CRUD Membengkak: Form modal tambah santri dan master jurusan/ruang bercampur dalam 1 file 1733 baris tanpa komponen terpisah.
4. Lembar Penilaian (/tpa, /rubrik, /wawancara) Issue: UX Friction
  • Candidate Selector Horizontal Scroll: Selector santri di atas memakai pill horizontal yang melar ke kanan saat santri bertambah puluhan, susah dicari cepat oleh asatidz.
  • 7 Tab Kepesantrenan Terisolasi: Penguji harus klik tab satu per satu (Tahsin -> Kitab -> Inggris -> Arab -> Hadits -> Adzan -> Sholat), tidak ada mode overview cepat.
  • Banner Wizard Berulang: Setiap halaman ujian membawa banner breadcrumb "1. Tes TPA -> 2. Tes Kepesantrenan -> 3. Wawancara" yang memakan ruang atas.
